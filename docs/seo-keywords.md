## Notes on Usage

- Every page should build its `<title>`, `<h1>`, and opening paragraph
  around **one primary keyword** from the list above — see
  `includes/seo-config.php` for how this is applied per page.
- Always pair a generic term with the school name and/or location
  ("primary school Kampala" alone is too broad and too competitive;
  "Mbuya Parents' School Kampala" is specific and winnable).
- When adding new blog/news posts through the Admin Dashboard, pick
  one Informational or Academic keyword above (or a new one parents
  are actually searching) and use it naturally in the post title and
  first paragraph.
