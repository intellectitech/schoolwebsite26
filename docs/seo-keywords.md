## Notes for whoever edits page copy next
- Every page's `<title>` and meta description already pull from
  `includes/seo-config.php` — update keyword phrasing there, not by
  hand-editing each page's `<head>`.
- Keep the school name + "Namugongo" in titles; that's the strongest
  local-search signal this site has (68% of searches start on Google —
  per the deck — and most of them will already include a location).
- When adding a new news article from the admin panel, write the title
  the way a parent would search for it (e.g. "Uganda Martyrs Primary
  wins Namugongo Zone football tournament" beats "Sports Update #4") —
  article titles feed straight into that page's `<title>` and URL slug.
